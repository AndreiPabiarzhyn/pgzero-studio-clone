# PGZero Studio

Браузерная среда для создания игр на [Pygame Zero](https://pygame-zero.readthedocs.io/).
Работает полностью в браузере — Python выполняется на стороне клиента через Skulpt.

Русскоязычный форк, основанный на [PGZ Studio](https://ed-info.github.io/pgz/) ([ed-info](https://github.com/ed-info)), с собственным интерфейсом и упрощённой панелью инструментов.

## Возможности

- Редактор Python-кода с подсветкой синтаксиса и автодополнением
- Запуск игр Pygame Zero в браузере
- Просмотр файлов проекта (код, изображения, звуки, музыка)
- Галерея ресурсов и редактор спрайтов
- Экспорт и импорт проекта в ZIP
- Пошаговый режим и точки останова
- Встроенный справочник по Pygame Zero

## Запуск

```bash
python -m http.server 8000
```

Откройте http://localhost:8000/index.html
