# PGZero Studio — design reference

Reference: [Linear on Refero](https://styles.refero.design/style/90ce5883-bb24-4466-93f7-801cd617b0d1). Adapt its compact, clearly separated surfaces and restrained interaction states to this project; the existing PGZero Studio components, colours, typography, icons, and accessibility take priority.

## Application
- Keep editor actions easy to scan and progressively group them as space narrows.
- Use a small number of surfaces with consistent spacing and visible keyboard focus.
- Let game screenshots carry the visual character of community game cards.
- Preserve theme contrast, localized text, and touch-friendly controls.
