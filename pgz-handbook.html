1. О Pygame Zero

Pygame Zero — это библиотека для начинающих, которая упрощает создание игр на Python. Она основана на Pygame, но скрывает сложные детали и позволяет сосредоточиться на логике игры.

Главные преимущества:

  • Не нужно писать главный цикл игры
  • Простой синтаксис для работы с графикой и звуком
  • Идеально подходит для обучения программированию

Пример самой простой программы:

import pgzrun

WIDTH = 800
HEIGHT = 600

# Создаём актёра (спрайт)
actor = Actor('alien')  # alien.png должен лежать в папке images/
actor.pos = (400, 300)

def draw():
    screen.clear()
    actor.draw()

def on_mouse_move(pos):
    actor.pos = pos

pgzrun.go()

2. Объекты

В Pygame Zero основные объекты — это спрайты, их ещё называют актёрами (Actor). Актёр — это спрайт с программным управлением (перемещение, поворот и так далее).

Создание актёра:

actor = Actor('image_name')

где 'image_name' — название файла изображения (без расширения), который должен находиться в папке images.

Совет: Изображения должны быть в форматах PNG или JPG и храниться в папке images рядом с файлом игры.

3. Окно

Размер окна игры задаётся переменными WIDTH и HEIGHT. Эти переменные должны быть определены в начале программы.

WIDTH = 800
HEIGHT = 600

player = Actor('player')
player.pos = 100, 56

Координаты в Pygame Zero начинаются с верхнего левого угла экрана (0, 0). Позиция актёра задаётся через свойство pos (или отдельно через x и y).

4. Перерисовка

Функция draw() вызывается автоматически, чтобы перерисовать все объекты, которые находятся на экране.

def draw():
    screen.clear()
    player.draw()
    enemy.draw()
    screen.draw.text("Счёт: " + str(score), (10, 10))

Важно всегда начинать с screen.clear(), чтобы очистить предыдущий кадр. Для рисования текста используйте screen.draw.text().

5. Спрайты и их свойства

У актёров есть много полезных свойств:

  • pos — позиция (x, y)
  • x, y — отдельные координаты
  • angle — угол поворота (в градусах)
  • opacity — непрозрачность
  • scale — масштаб (1.0 — исходный размер)
  • image — название текущего изображения
player = Actor('hero')
player.pos = (400, 300)
player.angle = 45
player.scale = 1.5

# Смена изображения
player.image = 'hero_angry'
Совет: Для анимации можно менять свойство image в зависимости от состояния игры.

6. Перемещение спрайтов

Перемещение объектов происходит в функции update(), которая вызывается перед каждой перерисовкой.

def update():
    if keyboard.right:
        player.x += 5
    if keyboard.left:
        player.x -= 5
    if keyboard.up:
        player.y -= 5
    if keyboard.down:
        player.y += 5

7. Использование клавиатуры

Pygame Zero даёт простой доступ к состоянию клавиш через объект keyboard.

def update():
    if keyboard.space:
        fire_bullet()
    if keyboard.a:
        player.x -= 3
    if keyboard.d:
        player.x += 3

Можно также использовать специальные функции для обработки нажатия клавиш:

def on_key_down(key):
    if key == keys.SPACE:
        create_explosion()
    elif key == keys.ESCAPE:
        exit()

8. События мыши

Обработка событий мыши выполняется через специальные функции:

def on_mouse_down(pos, button):
    if button == mouse.LEFT:
        print("Левая кнопка нажата в", pos)
    elif button == mouse.RIGHT:
        print("Правая кнопка нажата")

def on_mouse_move(pos):
    player.pos = pos

Вы также можете проверять состояние кнопок мыши в функции update():

def update():
    if mouse.LEFT:
        player.angle += 2

9. Звуки и музыка

Для работы со звуком используйте модуль music и объект sounds.

# Воспроизведение звука
def on_key_down(key):
    if key == keys.SPACE:
        sounds.jump.play()

# Управление музыкой
music.play('background_theme')
music.set_volume(0.5)

# Остановка музыки
music.stop()

Звуковые файлы должны находиться в папке sounds (для коротких звуков) или music (для фоновой музыки).

Поддерживаемые форматы: WAV, OGG, MP3 (в зависимости от системы).

10. Таймер

Для отложенного выполнения кода используйте функции модуля clock.

def spawn_enemy():
    enemies.append(Actor('enemy'))

# Создавать врага каждые 3 секунды
clock.schedule_interval(spawn_enemy, 3.0)

# Выполнить функцию один раз через 5 секунд
clock.schedule(game_over, 5.0)

def game_over():
    print("Время вышло!")

Чтобы отменить запланированное событие, сохраните ссылку на функцию:

def cancel_timer():
    clock.unschedule(spawn_enemy)

clock.schedule_interval(spawn_enemy, 2.0)

11. FAQ — частые вопросы по коду

Почему игра не запускается?
Проверь, что в проекте есть файл my_pgz.py, в конце написано pgzrun.go(), а отступы в Python одинаковые (4 пробела).

Что такое draw() и update()?
draw() рисует картинку на экране каждый кадр.
update() меняет положение героев и проверяет нажатия клавиш.

Как двигать героя?
Меняй actor.x и actor.y в update() или используй keyboard.left, keyboard.right и другие клавиши.

Где хранятся картинки и звуки?
Картинки — в папке images, звуки — в sounds, музыка — в music. Имена файлов без пробелов, латиницей.

Как нарисовать своего героя?
Нажми кнопку «Нарисовать» на панели или в галерее картинок, сохрани файл и используй его имя в Actor('имя_файла').

Что делать, если ошибка в коде?
Прочитай красное сообщение внизу, найди номер строки и исправь опечатку. Частые ошибки: забытая двоеточие :, неправильный отступ, неверное имя файла картинки.
